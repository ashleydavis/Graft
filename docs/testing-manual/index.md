# Testing manual index

The manual test steps for every top-level feature of Graft. See [README.md](README.md) for how the testing manual is laid out.

- [welcome](welcome/index.md): the welcome page, which Graft opens on while no repo is open, with Graft's mark, its name, a line describing Graft and an Open repo button.
- [about](about/index.md): the About page, which shows what Graft is.
- [repo-explorer](repo-explorer/index.md): the repo explorer page, which opens on the repo details pane, whose Commits link opens the commit pane listing the repo's commits, read a page at a time as the list scrolls.
- [help](help/index.md): the Help page, which says how to move between Graft's pages.
- [open-repo](open-repo/index.md): opening a repo from the File menu and with Ctrl+O.
- [new-window](new-window/index.md): opening a new window from the File menu and with Ctrl+N.
- [shortcuts-overlay](shortcuts-overlay/index.md): the keyboard shortcuts overlay, which `?` shows and `?` or Escape closes.
- [zoom](zoom/index.md): zooming the window with the keys and the View menu, and starting at the saved zoom.
- [layout](layout/index.md): the top bar with the breadcrumb trail and the theme menu, the left and right sidebars and the main content area every page shows in.
