# Keyboard shortcuts overlay

**ID:** shortcuts-overlay
**Spec:** Settled
**Implementation:** Complete

An overlay over every page that `?` or Ctrl+/ shows and `?`, Ctrl+/ or Escape closes. Ctrl+/ works in text boxes too, and the top bar reminds the user of it. It lists every shortcut in Ziggy's action list in one column, with a search box that filters them.

## Sub-features

None.
