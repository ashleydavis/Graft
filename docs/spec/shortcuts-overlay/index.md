# Keyboard shortcuts overlay

**ID:** shortcuts-overlay
**Spec:** Settled
**Implementation:** Complete

An overlay over every page that `?`, Ctrl+/ or the top bar's keyboard shortcuts button shows and `?`, Ctrl+/, Escape, a click outside it or its close button closes. Ctrl+/ works in text boxes too, and the top bar reminds the user of it. It lists every shortcut in Ziggy's action list in a group headed General, after the selected pane's or page's own keys when it has some, with a search box that filters every group.

## Sub-features

None.
