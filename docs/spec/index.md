# Spec index

Every top-level feature of Graft. See [README.md](README.md) for how the spec is laid out.

- [about](about/index.md): the About page, which Graft opens on.
- [commits](commits/index.md): the commits page, which lists the first page of the repo's commits.
- [help](help/index.md): the Help page, which says how to move between Graft's pages.
- [open-repo](open-repo/index.md): the File menu's Open repo item and its shortcut Ctrl+O, which open a local repo in the commit explorer.
- [shortcuts-overlay](shortcuts-overlay/index.md): the keyboard shortcuts overlay, which `?` shows and `?` or Escape closes.
- [zoom](zoom/index.md): zooming the window with Ctrl+Plus, Ctrl+Minus, Ctrl+0 and the View menu, which Graft saves and starts at.
- [layout](layout/index.md): the top bar with the breadcrumb trail and the theme menu, the left and right sidebars and the main content area every page shows in.
