# Repo details pane

**ID:** repo-details
**Spec:** Settled
**Implementation:** Complete

The first pane of the repo explorer. It shows the open repo's name and path, a Commits link that opens the commit pane to its right, a Changes link that opens the changes pane to its right and the repo's local branches, each of which opens the branch pane with only that branch's commits, and the repo's tags, each of which opens the tag pane to its right.

## Sub-features

None.
