# Keyboard shortcuts for the repo explorer

**ID:** repo-explorer-keys
**Spec:** Settled
**Implementation:** Complete

Move through the repo explorer, the columns of the repo explorer page, with the arrow keys, Page Up, Page Down, Home, End, Enter and Escape, as in the column view of macOS Finder, copy the selected commit's hash or file's path with Ctrl+C (Cmd+C on macOS), and return to it from any page with Ctrl+1 (Cmd+1 on macOS). M maximises the active pane and restores the panes, and C collapses and restores the active pane.

## Sub-features

None.
