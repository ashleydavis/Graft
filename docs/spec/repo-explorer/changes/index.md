# Changes pane

**ID:** changes
**Spec:** Settled
**Implementation:** Complete

The pane headed "Changes" that the repo details pane's Changes link opens. It lists the working tree's unstaged files and staged files in two lists, shows a selected file's diff in the file pane to its right, stages or unstages a whole file with the button on its row and commits the staged files with the message in its commit section.

## Sub-features

None.
