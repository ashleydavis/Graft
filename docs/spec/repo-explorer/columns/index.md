# Columns in the repo explorer

**ID:** commit-columns
**Spec:** Settled
**Implementation:** Complete

The repo explorer page lays out a commit and its files in columns that open to the right of the repo details pane, like the column view of a file browser: the commit pane when the Commits link is clicked, then the commit details pane when a commit is clicked, then the file pane when a changed file is clicked, or the "Commit details" pane with the commit's message and facts when the commit details pane's "Commit details" row is clicked. Each new pane can be closed, and every pane can be maximised to fill the repo explorer.

## Sub-features

None.
