# Columns in the repo explorer

**ID:** commit-columns
**Spec:** Settled
**Implementation:** Complete

The repo explorer page lays out a commit and its files in columns that open to the right of the repo details pane, like the column view of a file browser: the commit pane when the Commits link is clicked, then the commit details pane when a commit is clicked, then the file pane when a changed file is clicked. Each new pane can be closed.

## Sub-features

None.
