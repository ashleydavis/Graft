# Git commands in the right sidebar

**ID:** git-commands
**Spec:** Settled
**Implementation:** Complete

The right sidebar shows the two Git commands the active pane on the repo explorer page, or the page shown on every other page, ran most recently, the most recent first, under the `cd` that moves a terminal into the repo, each with a button that copies it and how long it took, with the total time of every command kept for the pane or page.
