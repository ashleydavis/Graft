# Layout

**ID:** layout
**Spec:** Settled
**Implementation:** Complete

The layout every page shows in: a top bar across the window with the breadcrumb trail and the theme menu, a left sidebar that minimises and expands, the main content area that shows the current page and a right sidebar that slides in and out.

## Sub-features

- [git-commands](git-commands/index.md): the Git commands the open page has run, shown in the right sidebar.
