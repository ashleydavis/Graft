# Columns on the commits page

**ID:** commit-columns
**Spec:** Settled
**Implementation:** Complete

The commits page lays out a commit and its files in columns that open to the right, like the column view of a file browser: the commit pane, then the commit details pane when a commit is clicked, then the file pane when a changed file is clicked. Each new pane can be closed.

## Sub-features

None.
