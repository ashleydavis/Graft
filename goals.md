# Goals

- A great Git client with a great UX that supports and improves the developer's process.
- A native app with a web UI, distributed to all desktop platforms.
- Every feature is amazing before moving on to the next.
- Really exceptional performance, no matter the size of the repo.
- Now that AI agents write so much code, diffing code effectively and clearly will be one of Graft's most important features.
- Diffing and staging hunks and files one at a time will be very important.
- Navigating files and chunks in a diff with the arrow keys must be easy, with a key to toggle a chunk's state (discard, unstage, stage).
- Stashing, staging and worktree management will be important.
- The whole app can be driven by keyboard shortcuts without using the mouse.
- Graft has no authentication features of its own. It relies on the user already having SSH keys and `gh auth` set up locally, and it uses their local identity.
- Graft is easy to run in development.
- Graft looks good and is usable when the window is shrunk to half or a quarter of the screen.

## Future

- A web based app that allows Graft to be controlled remotely.
- Graft runs in Ziggy's web mode, with the Zig server as the backend.
- The web page may be hosted, so Graft can be controlled from another computer.
